# Что делает

Отвечает на вопросы по 10 кураторским таблицам (вкладки одного Google Spreadsheet). Перед поиском читает `sheets-index.md`, по метаданным вкладок выбирает релевантные, потом открывает только их.

# Стратегия поиска

1. **Сначала читаю `sheets-index.md`** — там описание каждой из 10 вкладок: про что, ключевые колонки, диапазон строк, gid.
2. **Фильтрую по теме вопроса** — если спрашивают про класс — вкладка по классам, про семьи — вкладка Сергея Белова, про риски — churn Анны.
3. **Приоритет — свежесть и специализация.** Мастер-лист Натальи Шумиловой охватывает всех, но отстаёт. Конкретный куратор ведёт свою сущность актуально.
4. **При противоречии** — беру более свежую запись и помечаю расхождение с мастером.

# Формат ответа

Каждый ответ содержит:
- **Короткий факт** — кто/сколько/что
- **Источник**: имя вкладки + номер строки
- **URL строки**: `https://docs.google.com/spreadsheets/d/{ID}/edit#gid={GID}&range=A{N}:Z{N}`

Пример:
```
Куратор семьи Петровых — Анна Кожина.
Ведёт Петрова Фёдора (6Б, Годовой) в churn после инцидента с возвратом.
Источник: вкладка «04 Анна Кожина (churn)», строка 2.
URL: https://docs.google.com/spreadsheets/d/{ID}/edit#gid=12345&range=A2:G2
Примечание: в мастер-листе Натальи (вкладка 01) значится устаревшее «Ольга Тишина, 2024-09-12».
```
