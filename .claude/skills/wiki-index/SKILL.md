# Что делает

Рекурсивно проходит по всем файлам вики `.md`, извлекает из frontmatter метаданные (title, updated, author, status, category), собирает единый файл `wiki-index.md` в корне репозитория.

# Стратегия обхода

1. **Не полагаюсь на INDEX.md папок** — они кураторские и часто неполные. Обхожу все файлы напрямую.
2. **Читаю frontmatter каждого `.md`** — минимум: `title`, `updated`, `author`, `category`. Если нет frontmatter — использую имя файла и путь как фолбэк.
3. **Выделяю «закопанные» файлы** — префиксы `memo-*`, `sync-*`, `postmortem-*`, `board-prep-*`. В индексе помечаю их явно — там свежие решения.
4. **Сортирую внутри раздела по дате** — самые свежие сверху.

# Формат `wiki-index.md`

```markdown
# Wiki Index

## finance/
- finance/process-refund.md — Процедура возврата (актуально, 2025-01-20, Анастасия Журавлёва)
- finance/process-refund-short.md — Возврат краткая (актуально, 2023-06-01, О. Петрова)

## general/
- general/memo-2025-01-refund-review.md — Memo: пересмотр политики возврата (актуально, 2025-01-22, А. Журавлёва)
- general/faq-parents.md — FAQ для родителей (актуально, 2024-11-10)

## sales/
- ...
```

# Когда перестраивать

- Добавился или удалился документ в вики
- Переименовали файл
- Ответы `/wiki-search` стали странными или неполными

Запускаю руками, периодичность студент выбирает сам. Файл `wiki-index.md` живёт в корне репозитория — его читают оба скилла (`/wiki-index` пишет, `/wiki-search` читает).
