# Что делает

Проходит по всем вкладкам Google Spreadsheet «Таблицы кураторов», читает заголовки, первые строки, извлекает метаданные. Собирает `sheets-index.md` в корне репозитория.

# Стратегия индексации

1. **Получаю список вкладок через API** — для каждой узнаю title и gid.
2. **Читаю заголовки колонок** (первая строка) — это ключ к пониманию, что во вкладке.
3. **Читаю 3–5 первых строк данных** — по ним формулирую короткое описание «про что».
4. **Отмечаю мастер-листы** — вкладка «01 Наталья Шумилова» — агрегатор, отстаёт. Ориентируюсь на специализированные вкладки.

# Формат `sheets-index.md`

```markdown
# Sheets Index

Spreadsheet: {URL}

## Вкладка 01: Наталья Шумилова (мастер-лист)
- Про что: сводный лист всех учеников, senior-куратор. Часто отстаёт.
- Колонки: A=ФИО ученика, B=класс, C=тариф, D=куратор, E=семья, F=статус, G=обновлено
- Строк: ~91
- Gid: 0
- Обновлено: 2024-09-12

## Вкладка 04: Анна Кожина (churn)
- Про что: клиенты в риске ухода, свежий list
- Колонки: A=ФИО, B=класс, C=тариф, D=риск, E=причина, F=действие, G=обновлено
- Строк: ~15
- Gid: 789456
- Обновлено: 2025-10-02

## Вкладка 05: Сергей Белов (семьи)
- Про что: все семьи, включая многодетные (3+)
- Колонки: A=семья, B=отец, C=мать, D=дети с классами, E=статус многодетной
- Строк: ~28
- Gid: 123456
...
```

- Ответы `/sheets-search` стали странными
