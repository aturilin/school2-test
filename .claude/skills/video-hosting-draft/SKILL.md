# /video-hosting-draft

Готовит черновики для редактора. Первая половина human-in-the-loop: код предлагает — человек выбирает.

## Принципы

- **Интеллект — это ты (Claude).** Классификация предмета и сочинение вариантов — твоя работа, не скриптов.
- **Скрипты — только детерминированные операции** (Whisper, Pillow overlay, чтение/запись Sheet).
- **Три варианта должны принципиально отличаться по углу подачи**, не быть перефразировками.
- **Идемпотентность — обязательна.** Строка в Sheet ключуется по `video_filename`. Повторный запуск не дублирует.

## Шаги

### 1. Получить список видео, которых ещё нет в Sheet

```bash
.venv/bin/python scripts/cli.py list-pending
```

Вывод — имена `.mp4` по одному на строку. Если пусто — все уже в Sheet, работа закончена.

### 2. Для каждого видео

**2.1. Получить транскрипт.**

```bash
.venv/bin/python scripts/cli.py transcript <video_filename>
```

Скрипт вернёт текст на stdout. Если транскрипта нет — сам расшифрует через **локальный Whisper** (`openai-whisper`, модель `small`, первый запуск качает ~500 МБ) и закэширует в `inputs/transcripts/`.

**2.2. Классифицировать предмет (сам, по содержимому транскрипта).**

Варианты: `russian`, `math`, `physics`, `biology`. Категорически — **не по имени файла**, только по содержимому: первые 2-3 предложения обычно явно называют тему.

**2.3. Прочитать SPEC.md для этого предмета.**

`inputs/thumbnails/{subject}/SPEC.md` — правила генерации заголовков (длина, кейс, запреты). Обязательно.

**2.4. Сочинить 3 варианта заголовка и 3 описания.**

**Заголовки (строго по SPEC):**
- Длина 12–55 символов ВКЛЮЧИТЕЛЬНО (жёсткое ограничение).
- Sentence case. Без ALL CAPS, эмодзи, `!`, `?`, `…`, `.` в конце.
- Можно: двоеточие, тире, цифры.
- Без номера серии, класса, бренда канала.
- Избегать слов длиннее 14 символов (ломают word-wrap).

**Три принципиально разных ракурса (это критерий качества):**
1. **Прямой/безопасный** — декларативный, ключевой факт из урока.
2. **Эмоциональный** — вопрос или неожиданный ракурс.
3. **Инсайтный** — с цифрой, примером или обещанием «как сделать».

**Описания:** 2–4 предложения, 200–500 символов, конкретика по уроку, без эмодзи и восклицаний.

**2.5. Отрендерить 3 PNG обложки.**

Для каждого заголовка:
```bash
.venv/bin/python scripts/cli.py render <subject> "<title>" "<video_stem>_<1|2|3>.png"
```

Скрипт сам накладывает заголовок на `inputs/thumbnails/{subject}/template.png` по SPEC (HelveticaNeue Bold 128→44px, 3 строки max, white + shadow). Возвращает абсолютный путь к PNG. Если заголовок не влезает — скрипт вернёт ошибку: переделай заголовок.

**2.6. Записать строку в Sheet.**

Собери JSON с 11 полями и передай одной строкой:
```bash
.venv/bin/python scripts/cli.py append-row '{"video_filename":"...", "subject":"...", "title_1":"...", ..., "thumb_3":"/abs/path/..."}'
```

### 3. Отчёт

После обработки всех видео кратко отчитайся: сколько обработано, сколько пропущено (уже были в Sheet), сколько упало с ошибкой и почему.
