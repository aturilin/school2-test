# Что делает

Принимает вопрос на естественном языке от менеджера или аналитика. Под капотом вызывает `/wiki-search` (по корпоративной вики) и `/sheets-search` (по кураторским таблицам), объединяет находки и возвращает единый ответ с ссылками на оба источника.

# Стратегия оркестрации

1. **Парсю вопрос** — определяю, что из источников может быть релевантно:
   - Регламенты, политики, сроки, суммы → `/wiki-search`
   - Клиенты, кураторы, классы, статусы → `/sheets-search`
   - Если вопрос касается обоих — вызываю оба
2. **Вызываю скиллы параллельно** — каждый возвращает свой shortlist + ссылки.
3. **Сливаю результаты** — если они дополняют друг друга, показываю оба. Если противоречат (например, вики говорит одно, таблица — другое) — помечаю противоречие явно.
4. **Сохраняю структуру источника в ответе** — чтобы пользователь видел, откуда что.

# Формат объединённого ответа

```
Ответ: {короткая суть}

Из вики:
- {факт} — источник: {URL документа}

Из таблиц:
- {факт} — источник: {имя вкладки, строка, URL}

Противоречия (если есть):
- {что противоречит и что выбрано}
```

# Пример

Вопрос: «У меня на линии семья Петровых, просят скидку многодетным. Что с ними и какая актуальная скидка?»

```
Ответ: скидка 15%, семья ведётся Анной Кожиной.

Из вики:
- Актуальная скидка многодетным — 15% (general/memo-2024-09-discount-alignment.md, 2024-09-18)
- Устаревшая версия — 20% (sales/discounts-multichild.md, 2024-09-10)

Из таблиц:
- Петровы ведутся Анной Кожиной после инцидента сентября 2025 — churn-лист, строка 2
  https://docs.google.com/spreadsheets/d/{ID}/edit#gid=456789&range=A2:G2
- Петровы НЕ многодетные (только 2 ребёнка — Фёдор 6Б и Мария 9А) — вкладка «05 Сергей Белов», строка 14
  https://docs.google.com/spreadsheets/d/{ID}/edit#gid=567890&range=A14:E14

Противоречий нет. Скидка 15% многодетным — но Петровы не попадают под критерий (<3 детей).
```
